# doakickflip

A THUG Pro mod and companion app where a streamer's chat picks the tricks
they have to land in high combo mode.

## Language

**Yell**:
A trick that chat (or a test tool) asks the skater to land, named after the
games' own goals ("Nail the Tricks They Yell Out").
_Avoid_: request, trick request, command

**Nail**:
A yell is nailed when it clears off the stack: as soon as the trick is done,
or when the combo lands, depending on how tricks clear.
_Avoid_: land, complete, clear (for the yell itself)

**Nailed count**:
The number of yells nailed in the current run; the score.
_Avoid_: tricks-landed counter, score counter
