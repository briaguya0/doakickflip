# Does NeverScript's grammar cover everything THUG2 scripts use?

Type: research
Status: resolved
See: nsqb's wayfinder/v1 ticket 01 asks the same question; resolve there and link the answer here.

## Question

Does NeverScript (byxor's, and Revert's fork if it differs) cover every construct THUG2 / THUG Pro scripts use, notably `switch`, `elseif` and `Random*`? List any gaps. Context: notes/qb-lib.md (Direction, Prior art).

## Answer

Resolved in nsqb's wayfinder/v1 ticket 01 (research/neverscript-grammar-coverage.md there): upstream NeverScript doesn't cover THUG2; Revert's fork nearly does (gaps: counted loops, THUG Pro line markers); `elseif` isn't needed.
