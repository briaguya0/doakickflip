# What kinds of tricks exist, and how does the game name and count each?

Type: research
Status: open

## Question

Sweep the trick definitions for every kind of trick (normal, double / triple tap, special, flips and rolls, grinds, lips, manuals, reverts, anything else). For each: how the game names it, whether GetNumberOfTrickOccurrences counts it, and what glyphs it would get. Local extracted scripts only; nothing game-derived committed.
